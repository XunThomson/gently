# 宠物（Beta 1.0）

> 宠物是 `gently` 的一个**独立子系统**：自己的引擎（`pet-core`）、自己的数据库（`pet.db`）、
> 自己的窗口（`pet`）。音乐核心与它互不依赖（[ADR 0010](adr/0010-pet-core-crate.md)），
> 所以它可以在音乐窗口最小化时继续待在桌面上。

## 1. 打开它

**设置 → 宠物（Beta）→ 开启**。默认关闭：1.x 的音乐软件不替用户打开桌宠。

打开后右下角会出现一只宠物，跑在自己的置顶小窗里（200×160，无边框、不在任务栏）。
关掉开关即隐藏窗口，宠物数据仍然保留。

## 2. 它能做什么

| 行为 | 触发 |
|---|---|
| 待机动画 | 没有别的事 |
| 看向鼠标 | 光标在屏幕上移动（**仅 Windows**），16 个方向 |
| 摸摸 | 左键点宠物（有冷却，冷却内的点击静默忽略） |
| 喂食 | **右键点宠物**，或用设置页的「喂食」按钮（有冷却，冷却内会给提示） |
| 饿了 | 按时间衰减；饿了会演「失败」并冒一句气泡 |
| 播放中 | 演「奔跑」 |
| 换歌 | 演「审察」 |
| 走动 | 打开设置页的「在屏幕上走动」后，每 10–40 秒会走到桌面底部的另一个位置（演 unLeft / unRight） |

好感度、饥饿度、喂食/触摸冷却**跨会话保存**（写在 `pet.db` 里，退出时也会写回）。
好感分四档（拘谨 / 熟悉 / 亲近 / 依赖），档位只影响话术与可用的行为，不影响数值。

## 3. 窗口

- **拖动**：直接拖宠物本体（按住移动超过 5px 才开始拖，不会顺手「摸」它一下）。
  拖动是**宠物自己跟着光标走**（渲染器自己搬窗口，不是系统的「拖窗口边框」）：
  拖动过程中画面照常动（会换成「被拎起来」的动作），松手后停在原地、位置记住。
  窗口里**只有宠物本体**是可交互的，其余透明区域点击穿透——所以不会有「拖到一块看不见的区域」的感觉。
- **位置记忆**：拖到哪下次还在哪；副屏拔掉/分辨率变了会自动夹回可见区域。
- **点击穿透（锁定）**：设置页的开关。打开后鼠标点击**穿过**窗口，宠物完全点不到、也拖不动——
  适合宠物压在编辑器/浏览器上时。解锁入口只在设置页（锁上后它自己收不到点击）。
- **自动穿透**：光标不在宠物身上时，窗口本来就穿透（**仅 Windows**）；在宠物身上时点得到。
- 主窗口最小化、被别的应用盖住都不影响宠物；**关主窗口 = 退出应用**（宠物一起收）。

## 4. 换宠物 / 导入宠物包

设置页 → 宠物 → 导入宠物包：

1. 把 `pet.json` **拖进投放区**（或粘贴 JSON），把图集拖进来（或点「选择图集」）；
2. 类型不对的文件会被忽略；同 id 覆盖安装会**保留好感与饱食度**；
3. 白底（没有透明通道）的图集会被**自动去底**；装完会记校验和，之后文件被改坏会明确报错。

支持两种格式（详见 [`pet-package.md`](pet-package.md)）：

- **我们自己的** `pet.json`：可以声明动画、行为表、图集布局与 look 两行；
- **社区 [Codex Pet](https://codexpet.top)** 的 `pet.json`（`{id, displayName, spritesheetPath}`）：
  v1（8×9）与 v2（8×11，含 16 个 look 方向）都能直接用。

> 社区素材的许可是 **CC BY-NC 4.0**（非商业）：自己导入用没问题；
> 我们**不内置、不推荐、不预置**任何第三方宠物（[ADR 0005](adr/0005-neutral-third-party.md)）。

## 5. 数据在哪

| 路径 | 内容 |
|---|---|
| `<数据目录>/pet/pet.db` | 宠物清单、好感/饥饿、出战宠物、图集索引与校验和 |
| `<数据目录>/pet/packages/<id>/` | 导入的图集文件（库里只记文件名，搬家后仍有效） |

数据目录整体搬家（设置 → 数据目录 → 迁移）会把它一起搬走，并逐库做完整性自检。

## 6. 调试面板（开发用）

设置页宠物卡片底部的**「调试面板（开发）」**（默认收起）用来看宠物的三层真实状态：

| 行 | 来源 |
|---|---|
| 出战宠物 | 核心（`pet.state`） |
| 宠物窗口 / 记住的位置 | 宿主窗口（位置与可见性）+ localStorage |
| 图集 | `pet.atlas`（文件名与体积；没有图集时显示「程序化渲染」） |
| 宠物核心 | 核心版本 + 当前包要求的版本（`minPetCoreVersion`；没写就是「无要求」） |
| 窗口开关 | 点击穿透 / 走动的当前值（localStorage，与设置页同一份） |
| 最近一帧 | **展开面板就会自动读一次**：调一次 `pet.tick`（**`dtMs = 0`，不会推进动画**），显示 `animation=名字(序号) frame=… look=… bubble=…` 与往返耗时；读失败时把原因（含抛出的异常）显示出来，可点「探测一帧」重试 |

按钮：探测一帧、喂食、摸一下、重置窗口位置（清掉记住的位置再重新摆回右下角）。

## 7. 已知边界（Beta 1.0 的实话）

- **只有一只**在展示（存储与 API 支持多只，为将来独立化预留）；
- **走动是宿主在挪窗口**（宠物核心只按方向挑动画）：光标**连续**放在宠物身上约 0.6 秒它才会停住
  （擦一下就停会让动画闪），锁定（点击穿透）状态下照常走；
- **动画切换有 160ms 的确认期**：同一个状态要持续一小会儿才换动画，避免「跑 → 待机 → 跑」闪一下；
  点一下、换歌这类动作是**立刻**生效的；代价是「走起来」比按下晚约 0.1 秒；
- **各行素材的大小会被对齐**：内置包给每个动作写了 `fit.scale`（0.8–1.08），切动画时角色不会突然变大变小；
  「失败 / 等待」两行本来就是头部特写（不是全身），现在只做到「头一样大」；
- **拖动时宿主不插手**：拖动期间不切穿透、也不自己走动（`gently:pet:dragging`），避免拖到一半窗口被切成穿透而断掉；代价是**拖动时它不转头**（这是有意的取舍）；
- **看向鼠标 / 自动穿透只在 Windows**：其它平台宠物照常显示，但不看鼠标、也只能用手动锁定；
- 自动穿透按**精灵的外接矩形**判定，不是逐像素 alpha（边缘几像素仍算「在里面」）；
- 内置宠物的图集是 9 行的 v1 素材：它有 look 的位置但没有 look 行，所以「看鼠标」要装 v2 素材才看得见；
- 宠物包不提供文案：气泡只能用宿主已有的少数文案键；
- 宠物包可以声明「要求的核心版本」：高于本机核心的包会被**拒绝安装**并说明原因（不会装上一个画不对的包）。
