# STATE

## 本轮目标

按反馈优化五点：搜索页冗余搜索框、多音源展示与播放隐患、歌词当前行辨识度、播放列表不可控、播放条缺音质选择。

## 已完成（第五轮）

### 1. 搜索页冗余搜索框
移除搜索视图自带的 `SearchBox`（顶栏搜索已足够），工具条改为放音源筛选。

### 2. 多音源架构（本轮核心）
原设计「把所有源的数据整理后集中展示」的隐患已按两个方案同时解决，且在设置里可选：

- **聚合展示（默认）**：`groupTracks` 按 (标题, 歌手) 合并 —— 同一首歌只出现一条，
  多音源作为 `candidates`；新增 3 个真实注册的模拟音源
  （内置示例源始终可播 / Bilibili 约 1/4 不可播 / 网易云约 1/3 不可播），
  用来真实复现「同一首歌多条目」与「某源某曲播不了」两个问题。
- **播放期自动回退**：播放时按候选顺序 `resolveUrl`，失败即记入 `failedSources` 并试下一个，
  全部失败才退回模拟时钟；播放条音源选择器展示当前在播源、回退提示，并支持手动切换。
- **页面音源筛选**：`SourceFilter` 提供两种样式（横向标签 / 列表抽屉），设置里切换；
  排行榜 / 热门推荐 / 搜索结果已接入；分源模式下必须锁定一个音源。
- **音质**：`pickQuality` 在期望档位不可用时按源能力降级，实际在播档位显示在播放条。
- **启用状态**：插件管理页的开关写入注册表，注册表是「哪些源参与聚合与回退」的唯一来源。

### 3. 歌词样式
当前行：品牌色 + 更大字号 + 更粗字重 + 药丸背景 + **上下虚线引导线**（激活行才显示，
非激活行用同宽度透明边框避免跳动）+ 轻微放大；非激活行降低透明度、悬浮恢复；
滚动容器加渐变遮罩，滚动位置一目了然。

### 4. 播放列表（队列）
从「不可控」改为可控：分「正在播放 / 接下来播放 / 已播放」三段；
每行可上移、下移、移除（当前曲目不可移除）；表头可清空队列；
点击条目**不再关闭抽屉**；打开时自动把当前曲目滚到中间。

### 5. 播放条音源与音质
右侧新增两个选择器：音源（含自动回退提示与不可用标记）、音质（不支持的档位置灰）。
