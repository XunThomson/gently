# STATE

## 本轮目标

按反馈继续优化 UI 与补齐功能，并托管到 `http://192.168.92.139:3000/xun/gently.git`。

## 已完成（第二轮）

- **主题双入口分离**：灯泡 = 明暗背景切换；调色板 → `/theme` 主题市场（6 套预设，数据在
  `src/config/theme/presets.json`，只覆盖 palette / scheme，其余继承主题配置）。
  `themeMode` 与 `themePresetId` 持久化到 localStorage，挂载前注入避免闪烁。
- **收藏 / 歌单完整化**：新增 `collection` 切片；侧边栏展示收藏与歌单（数量、折叠、新建、悬浮删除）；
  `/favorites`、`/playlist/:id` 独立视图；行操作与详情页支持收藏切换、加入 / 移出歌单。
- **播放条现代化 + 反直觉修正**：列表点击当前曲目 = 播放/暂停（`playOrToggle`），
  其他曲目 = 切歌；主按钮在无曲目时禁用；进度条支持点击 / 拖拽 / ←→ 微调；
  封面与曲名进入歌曲详情；新增收藏按钮。
- **设置去重**：侧边栏移除「设置」，只保留右上角齿轮（冒烟测试断言守护）。
- **歌曲详情 + 歌词页**：`/now-playing`，大头图 + 元信息 + 收藏 / 下载 / 加入歌单；
  歌词随播放高亮、自动居中、点击跳转；歌词 mock 由曲目稳定哈希生成。
- **补齐缺失功能**：下载队列支持从列表 / 详情页「下载」入队，并由 mock 下载引擎每秒推进进度直至完成；
  本地音乐「在文件夹中显示」；最近播放清空。
- **UI 与能力对齐**：非 Tauri 环境（浏览器 / vite dev）下原生窗口控制按钮禁用，
  避免「点了没反应」的 UI 与效果不一致。
- **视觉现代化**：更大圆角与更柔和分层阴影、表头吸顶、行高亮 / 播放中指示条、
  侧边栏加宽并加选中指示条、播放条加高并加大封面、徽标与行内操作改为柔和药丸样式。
- **工程**：`__APP_VERSION__` 由 vite define 注入（版本单一来源 package.json）；
  冒烟测试扩到 103 项（新增主题预设、collection、playOrToggle、歌词、下载引擎、导航菜单断言）。
